# man牛界面与交互清单（v0.5.6）

## 主界面

1. 顶部品牌区
   - 展示当天日期，以及由营养计划自动判断的“训练日 / 休息日”。
2. 今日摄入
   - 汇总当天热量、剩余热量及碳水/蛋白质/脂肪进度。
   - 目标值来自当天对应的训练日或休息日计划。
3. 主界面版块排序
   - 今日摄入、体重趋势、餐次进度、今日提示和数据管理均可长按后上下拖动换位；抓取时显示放大、荧光描边与阴影，换位使用平滑动画，顺序保存在本地并随备份导出/恢复。
4. 体重趋势
   - `+` 打开“记录体重”弹窗。
   - 14天、30天、60天、半年、至今切换图表时间范围。
   - 点击图表数据点，或长按后左右滑动，连续显示经过日期的体重和热量详情。
   - 无真实体重时展示带“演示”标记的示例数据。
5. 四餐进度
   - 设置按钮打开“每日营养计划”。
   - `+` 打开“记录饮食”。
   - 点击早餐、午餐、晚餐或宵夜行，打开“记录饮食”并预选对应时段。
   - 每餐展示热量进度和由计划换算出的宏量目标。
6. 今日提示
   - 根据是否有记录、热量是否超标、蛋白质进度自动给出建议。
7. 记录饮食主按钮
   - 打开“记录饮食”弹窗。
8. 最近饮食
   - 展示最近 5 条记录的食物、餐次、来源、宏量和热量。
9. 数据管理
   - 页面最下方的“保存中心”统一提供“保存全部数据”和“恢复数据”；保存全部数据时会先保存当前身体设置，再直接执行完整备份。
   - 第一次“保存全部数据”调用系统文件创建器并记住文件授权；以后直接覆盖同一个 JSON，不再重复弹出确认。仅当原文件被删除或权限失效时重新选择保存位置。
   - “恢复数据”调用系统文件选择器；成功或失败均 Toast 反馈，成功后刷新界面。

## 记录体重弹窗

- 输入 20–400 kg 的数字；合法后“保存体重”可用。
- 展示最近 5 条记录，帮助用户判断输入是否异常。
- 保存后写入本地并刷新主界面。
- 右上角关闭、系统返回键或点击弹窗外区域均可取消。

## 每日营养计划弹窗

- “每日目标”页：分别编辑训练日和休息日的碳水、蛋白质、脂肪；热量按 `碳水×4 + 蛋白质×4 + 脂肪×9` 实时计算。
- 可选择每周训练日；当天模式由星期自动判断。
- “餐次分配”页：按克数分别配置训练日五餐与休息日四餐的碳水、蛋白质、脂肪。
- 修改每日目标时，各餐按现有比例自动缩放；按早餐到后续餐次逐项填写时，已手动填写的数值锁定不再回改，剩余克数只在尚未填写的餐次间自动分配。
- 所有校验通过后才可保存；保存后写入本地并刷新所有目标与进度。

## 记录饮食弹窗

- 自动推断餐次；从四餐进度进入时直接预选对应餐次。
- 快速选择合并自定义常用食物和内置参考食物，去重后显示前 8 个；点击填入食物，长按后卡片会放大并显示荧光描边与阴影，左右拖动可平滑地与相邻卡片换位，调整后的顺序保存在本地并随备份导出/恢复。
- 搜索同时覆盖本地参考值和 Open Food Facts；支持键盘搜索键、加载态、空结果和结果反馈。
- 选中食物后，50/100/150/200g 快捷份量或自定义克数会自动换算宏量。
- 手动修改名称或宏量后解除当前食物绑定，避免后续份量变化覆盖用户输入。
- 热量始终由三大营养自动计算。
- 可把当前录入保存为每 100g 的常用食物预设。
- 名称非空且热量大于 0 时才能记录；保存后写入本地并刷新主界面。

## 通用弹窗行为

- 深色统一容器、顶部拖拽视觉提示、右上角关闭。
- 长内容区独立滚动，底部主按钮固定，避免键盘或滚动后丢失提交入口。
- 禁用态由输入校验驱动，不使用仅靠 Toast 的事后拦截。
