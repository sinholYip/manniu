# man牛 UI 设计规范

## 1. 设计原则

- **训练感**：深黑底色、强对比数字、荧光青柠用于关键动作与结果。
- **数据优先**：先展示结论，再展示单位、说明和计算依据。
- **一致胜过装饰**：相同层级使用相同字号、边距、圆角和描边。
- **克制高亮**：一个版块最多一个主要荧光绿焦点，避免整屏发光。
- **可操作**：按钮、输入框和可点击日期必须具有明确边界与状态反馈。

## 2. 色彩令牌

| 用途 | 名称 | 色值 |
|---|---|---|
| 页面背景 | Background | `#050505` |
| 主卡片 | Surface | `#0D0D0F` |
| 抬升控件 | Raised | `#151517` |
| 选中弱背景 | Accent | `#20220C` |
| 主文字 | Ink | `#F7F7F5` |
| 次文字 | Muted | `#8F8F93` |
| 卡片描边 | CardOutline | `#2A2A2C` |
| 控件描边 | Outline | `#3A3A3D` |
| 品牌主色 | Lime | `#D7FF2F` |
| 上升/警示 | UpRed | `#FF5C61` |
| 下降/完成 | DownGreen | `#63D49B` |

荧光绿只用于：当前导航、主按钮、关键结果、选中态和重要进度。

## 3. 字体层级

| 层级 | 字号 | 字重 | 用途 |
|---|---:|---|---|
| 页面标题 | 30sp | Black | 饮食计划、训练计划、我 |
| 版块标题 | 18sp | Bold | 今日摄入、参考热量、动作安排 |
| 正文 | 13sp | Regular/SemiBold | 主要说明与数据标签 |
| 辅助文字 | 11sp | Regular | 单位、公式、提示、来源 |
| 核心数字 | 28–42sp | Black | 热量、体重、BMI 等结果 |

- 页面标题与副标题统一左对齐。
- 数字与单位使用基线对齐；单位使用 Muted，不与数值争抢视觉焦点。
- 不通过随意增大标题制造层级，层级由固定字号、字重和间距共同建立。

## 4. 间距与栅格

- 页面水平边距：20dp。
- 页面顶部：22dp；页面底部：36dp。
- 主版块间距：16dp。
- 卡片内部边距：18dp。
- 卡片内部主要元素间距：12dp。
- 紧邻标签与内容：6–8dp。
- 所有主页面使用相同左边界，不单独缩进版块标题。

## 5. 圆角与边界

- 主卡片：20dp，1dp `CardOutline` 描边。
- 输入框、按钮、日期卡和小型控件：12dp。
- 弹窗：24dp。
- 胶囊选择器、进度条：全圆角。
- 同一组件的背景、描边、裁剪和阴影必须引用同一个 Shape 令牌。

## 6. 组件规范

### 页面头部

- 标题 30sp Black，副标题 13sp Muted。
- 标题和副标题左对齐；头部整体参与页面 16dp 垂直节奏。

### 内容卡片

- 使用 Surface、20dp 圆角、1dp CardOutline。
- 标题位于卡片左上角，不使用无意义的前置图标。
- 一个卡片只承载一个明确任务或一组强相关数据。

### 按钮

- 主按钮：Lime 背景、Background 文字、12dp 圆角。
- 次按钮：透明或 Surface 背景、Lime 描边与文字。
- 禁用状态由组件状态控制，不只依赖提示信息。

### 输入框

- 统一 12dp 圆角、单行输入、清楚标注单位。
- 同组输入框等宽、等高、间距一致。

### 弹窗

- 所有业务弹窗必须使用统一的 `AppModalSheet`，以“记录体重”弹窗为基准，不得在调用处单独设置宽高或另建样式。
- 弹窗宽度占满可用宽度，屏幕四周保留 12dp 安全间距；最大高度统一为 680dp，并自动适配更小的屏幕。
- 弹窗使用 Background 背景、24dp 圆角和 1dp CardOutline 描边。
- Android 12 及以上使用 40dp 的跨窗口背景模糊和 24% 暗色遮罩；系统不支持或关闭跨窗口模糊时，降级为 72% 暗色遮罩。
- 头部统一为 24sp Bold 标题、可选 12sp Muted 副标题和右上角 38dp 关闭按钮；头部内边距为左 20dp、上 16dp、右 12dp、下 10dp。
- 正文区域水平内边距为 20dp、内容间距为 12dp；内容超过可用高度时只滚动正文，头部和底部操作区保持可见。
- 底部操作区内边距为左 20dp、上 14dp、右 20dp、下 18dp；主要按钮占满宽度且高度为 52dp。
- 新增、编辑、计划、体重和训练类弹窗都遵循同一结构；差异只能来自标题、副标题、正文内容和操作文案。

### 状态

- 当前/选中：Lime。
- 普通：Ink。
- 次要/未激活：Muted。
- 警示或超标：UpRed。
- 休息日可选择，但不得出现添加训练动作入口。

## 7. 页面应用规则

- **饮食计划**：卡片化呈现摄入、趋势、餐次与提示，记录饮食为唯一主操作。
- **训练计划**：训练日和休息日都可选择；休息日只展示恢复状态，不允许添加动作。
- **我**：身体数据、核心指标、参考热量、饮食参考和保存中心分别使用独立主卡片。
- 三个主页面必须共享页面边距、标题层级、卡片 Shape、描边和版块间距令牌。
